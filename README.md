# MemTrack

MemTrack is a lightweight runtime memory tracking and debugging tool written in C.

## Project Status

🚧 Currently under development.

## Planned Features

- malloc tracking
- calloc tracking
- realloc tracking
- free tracking
- Memory leak detection
- Double-free detection
- Invalid-free detection
- Allocation statistics
- Peak memory tracking
- Custom hash table for allocation metadata
